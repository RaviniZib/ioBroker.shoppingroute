ShoppingRoute 0.5.1 fixes the management-page saving and shopping-item movement issues reported with 0.5.0, with a focus on comfortable phone use.

- Create and verify actual Alexa lists; add shopping items directly, including to an empty list.
- Fix end-drop areas, insertion positions, touch dragging and empty return markets; restore drag ordering for markets, product groups and walking routes.
- Automatically save structural changes and selections; retain typed edits until Save, and queue rapid edits without retry loops.
- Keep local saves free of unnecessary Amazon checks and persist learned catalogue data without restarting the adapter instance.
- Show immediate progress for longer Alexa moves and obtain the final result without the previous UI timeout failure.
- Safely resolve uniquely named items after Alexa changes their IDs; never guess between duplicate names.
- Update German and English feedback, READMEs and help access.

Validated with 204 automated tests, lint/type checks and package checks, plus live save/readback checks and user-confirmed operation. Alexa write limits, Dry Run and verification safeguards are preserved.

After updating, fully reload the ShoppingRoute management page. Managed Alexa lists must remain sorted A–Z.
